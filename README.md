#  Task Manager 

A simple and clean **Task Manager web application** built using HTML, CSS, and JavaScript. Allows users to add, edit, delete, and filter tasks with priority levels and due dates. Tasks are saved in the browser so they persist even after page refresh.

---

##  Features

* Add tasks with priority level and due date
* Three priority levels — High, Medium, Low
* Mark tasks as completed with checkbox
* Edit existing tasks
* Delete tasks
* Filter tasks — All, Completed, Pending
* Tasks saved in localStorage — data persists after refresh
* Empty state messages for each filter
* Task count display

---

##  Technologies Used

* HTML
* CSS (Flexbox, Linear gradient)
* JavaScript (DOM manipulation, localStorage, Event listeners)

##  How It Works

* User types a task, selects priority and due date
* Click **Add** or press **Enter** to add the task
* Tasks appear in the list with priority color and due date
* Checkbox marks task as completed
* **Edit** button allows updating task name
* **X** button deletes the task
* Filter buttons show All, Completed, or Pending tasks
* All tasks are saved in localStorage automatically
